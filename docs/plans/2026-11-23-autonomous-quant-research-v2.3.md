> **결과를 본 뒤의 변경인지에 대한 공개.** holdout(H_hist, H_fwd) 질의는 0건이다. 연구 창의 S3 확인 결과는 이미 봤다. 그래서 다음을 지킨다.
> 1. 이미 등록된 규칙(ADR-049)을 적용하는 것은 기준 변경이 아니다.
> 2. 공간 변경(lookback 상한)은 연구 블록 길이에서만 유도한다. 성과로 정하지 않는다.
> 3. 재실행과 새 셀의 모든 평가는 trial로 세고, S3 판정은 누적 N에 더한다. 이미 평가한 trial은 지우지 않는다.
> 4. 새 셀(결합, Ridge)은 첫 실행 전에 구성 신호·설정·판정을 고정한다(부록 A).
> 5. 기준선 함수와 누적 N 규칙은 바꾸지 않는다.

## 2. 라벨 체계 v3 (v2.2 §6 개정, ADR-050)
### 2.1 원인 코드
| 코드 | 정의 | 다음 행동 |
|---|---|---|
| `error` | 배치가 예외로 끝남 | 셀 은퇴(기존) |
| `data_missing` | 필요 데이터셋이 없거나 커버리지 80% 미만, 또는 선물 백테스트에 펀딩 데이터가 없음(§4) | 수집 큐, 데이터가 오면 재개방 |
| `infeasible` **(신규)** | 셀의 공간에 실행 가능한 조합이 없음(§5) | 셀을 열지 않는다. 예산·N 미차감 |
| `no_signal` | S1·S2에서 평가할 것이 없거나, 선택 구간 비용 후 SR ≤ 0이고 비용 전에도 양수가 아님 | v2.2 §6 유지 |
| `cost_dominated` | 비용 전 양수, 비용 후 SR ≤ 0 | v2.2 §6 유지 |
| `sparse` | 노출 5% 미만으로 판정 불가 | v2.2 §6 유지 |
| `unstable` | 선택 구간 SR > 0, 확인 구간 SR ≤ 0 (구현 정의를 채택) | 국면 축(§8), 더 긴 창 |
| `below_bar` **(신규)** | 확인 SR > 0이지만 결합 확인 미충족. 하위 사유: `no_cross`(교차 측정 없음), `sign_mismatch`(교차 SR ≤ 0), `pooled_below`(결합 SR ≤ 기준) | 종료 |
| `candidate` | 결합 확인 통과 | 검증기 제출 |
- 배치마다 종료 코드는 1개다. 판정 순서는 위 표 순서다.
- 앞 단계 사유(`no_signal`, `cost_dominated`)로 끝난 배치도 S3가 돌았으면 그 사실과 확인 SR을 요약에 남긴다. 그 S3는 누적 N에 들어간다(기존 그대로).
### 2.2 재집계
- c1의 103배치에 v3 라벨 함수를 적용한 교차표를 만든다. 계산은 다시 하지 않는다(trial 증가 0).
- `sparse` 배치 가운데 §5 상한을 넘는 lookback 조합의 비율을 함께 낸다.
### 2.3 문서 정정
- v2.2 §5.3 제목을 "계열 15개"로 고치고 구현 대응표를 붙였다(v2.2 문서).

## 3. S3 결합 확인 (ADR-049 결정 3 그대로)
- 셀의 선택 구간 최선 spec을 자기 창 확인 구간에서 재고(S3), 양수면 **같은 spec**을 다른 창 확인 구간에서 1회 더 잰다(교차 S3).
- 후보 조건: 자기 S3 > 0 ∧ 교차 S3 > 0 ∧ 결합 SR > E[max | N, T]. N = 두 확인 구간에서 판정한 S3 누적 수 + 2, T = 두 확인 구간 일수 합.
- 단일 창 기준은 판정에 쓰지 않는다(현재 구현과 같다).
- **검정력 표(새 요건, 보고용).** `s3_power(T, N, 참 연 SR)`을 두고 라운드가 시작될 때 그 시점 N으로 표를 보고서에 쓴다. 기준선 함수는 바꾸지 않는다. 추정(같은 근사): N 78 → 기준 연 SR 약 2.1, N 300 → 약 2.5, N 600 → 약 2.7.

## 5. 실행 가능한 공간 v3 (v2.2 §5 개정, ADR-051)
- **원칙.** 상한은 연구 블록 길이에서만 유도한다. 워밍업이 봉인 구간이나 다른 블록에 닿는 결정은 거부한다(v2.2 §2.1 유지).
- **워밍업.** 모든 창·주기에서 고정 90일(월 경계로 올림, 연구 창의 첫 3개월). 사용자 결정(2026-11-23).
- **분할.** 워밍업을 뺀 달을 70/30으로 나눈다(기존 규칙). 선택 ≥ 9개월, 확인 ≥ 4개월이어야 한다.
  - w2: 워밍업 2024-12~2025-02, 선택 약 11개월, 확인 약 5개월. w1: 선택 약 23개월, 확인 약 10개월.
- **축 상한(봉).** 창 연산(수익률, z점수, 표준편차, 평균, 고·저가) ≤ 90일 ÷ 봉 길이. EMA는 span × 3 ≤ 90일.

| 주기 | 창 연산 최대 | EMA span 최대 |
|---|---|---|
| 1h | 2,160 | 720 |
| 4h | 540 | 180 |
| 1d | 90 | 30 |

- **적용 규칙(기계적).** 각 축은 v2 공간의 시작값과 간격을 유지하고 끝값만 상한 미만으로 자른다. 축의 시작값이 상한 이상이면 그 (계열, 주기) 셀은 `infeasible`이다.
  - 결과: `trend@1d`(slow 시작 48 > 30), `volatility@1d`(long 시작 96 > 90)는 `infeasible`. 그 밖의 계열은 범위만 줄어든다.
  - 비중의 변동성 창과 신호 평활도 같은 상한을 지켜야 한다. 넘는 선택지는 그 주기의 축에서 뺀다.
- **S0 검사.** spec의 필요 워밍업(`strategy/ops.lookback`의 중첩 합)이 블록 워밍업의 봉 수를 넘으면 S0에서 거부한다.
- **기존 trial.** 지우지 않는다. 누적 N에도 그대로 남는다.
- **대가.** 일봉 90봉을 넘는 느린 신호(6~12개월 모멘텀 등)는 이번 범위에서 포기한다.

## 6. 결합 셀 M0 (ADR-053)
### 6.1 목적
계열 하나하나는 약해도 서로 상관이 낮으면 결합해서 SR이 오를 수 있다. 이것을 시도 수 최소로 먼저 확인한다.
### 6.2 셀과 구성 신호
- 셀 = (`combo` × 주기 × 유니버스 × 창).
- 구성 신호: 횡단면 순위 계열을 **기준 매개변수**로 계산해 시점별 횡단면 z점수(`zscore_xs`)로 바꾼 값. 부호는 각 계열 템플릿의 방향(매수 쪽이 양수)으로 맞춘다.
- 기준 매개변수 = §5 상한을 적용한 축 범위의 중간 격자점(아래쪽으로 내림). S2·S3에서 고른 최선 매개변수는 쓰지 않는다.
- 입력 계열: `xs_reversal`, `momentum`, `low_vol`, `liquidity`, `premium_basis`, `funding_carry`, `funding_basis`. 새 데이터 tier가 `done`이면 그 셀에 `oi_positioning`, `taker_flow`, `spot_basis`를 더한다(데이터 버전이 달라지므로 별도 판정).
### 6.3 설정 (셀당 2개)
- `lin_eq`: 동일 가중 평균.
- `lin_ic`: 가중치 = 선택 구간 앞 75%에서 잰 신호별 IC의 HAC t(음수는 0, 합 1로 정규화). 확인 구간에서 다시 추정하지 않는다.
- 포트폴리오 구성은 고정 1개: 분위 0.8 양방향, 변동성 목표, 리밸런스 24h, 무거래 밴드 2%, 거래 종목 수 20.
- 가중치는 숫자 상수로 spec에 들어간다. 검증기는 기존 경로로 그 spec을 잰다.
### 6.4 판정과 N
- 두 설정을 선택 구간 검증 분할(마지막 25%)에서 비교해 최선 1개만 S3로 보낸다. 이후는 §3과 같다.
- 셀 배치당 누적 N 증가: 자기 확인 1 + 교차 확인 1(교차는 자기 확인이 양수일 때만).
### 6.5 진단(판정에 쓰지 않음)
구성 신호 간 상관행렬, 단일 계열 최선 대비 결합의 선택 구간 SR 차이.

## 7. Ridge 셀 M1-R (ADR-054)
- 목적: 신호별 가중을 회귀로 정한다. 새 정보를 만들지는 않는다. numpy만 쓴다(새 패키지 없음).
- 셀 = (`ridge` × 주기 × 유니버스 × 창).
- 특징: §6.2 구성 신호 + 고정 보조 특징(최근 수익률 1·5·20봉, 실현 변동성 20봉, 거래대금 순위, 프리미엄 z점수 20봉). 모두 횡단면 z점수로 바꾼다.
- 라벨: 다음 24h 수익률의 횡단면 순위(0~1). 결정 시각 + 지연 뒤의 가격으로 만든다.
- 학습: 선택 구간 앞 75%. 학습 끝의 라벨 구간(24h)은 purge하고, 검증 분할과의 사이에 max(특징 lookback, 24h)의 embargo를 둔다. 특징이 비어 있는 행은 학습에서 뺀다.
- 설정 3개: α ∈ {1, 10, 100}(표준화된 특징 기준). 계수는 숫자 상수로 spec에 들어가고 확인 구간에서 다시 학습하지 않는다.
- 포트폴리오 구성, 판정, N 증가는 §6.3·§6.4와 같다.
- Director(LLM)는 M0·M1 설정을 제안하지 않는다. 그래서 이 셀의 후보는 사전 등록 공간 기원이다(v2.2 §2.2: H_hist로 판정, H_fwd는 보고).
- 검증: 미래 값 특징 누수 테스트, purge·embargo 경계 테스트, 계수 재현, 라벨을 블록 단위로 섞은 과적합 탐침.

## 8. 재실행과 라운드 (ADR-055)
- 새 캠페인 `c2`를 공간 v3로 시작한다. c1은 보관한다. c1의 S3 판정 수는 c2의 기준에 더해진다(ADR-049 결정 2).

| 라운드 | 내용 |
|---|---|
| G1′ | w2 · 4h/1d · 상위 100 (기존 계열, 펀딩 포함) |
| G2′ | w1 · 4h/1d · 상위 100 |
| M0 | 결합 셀, 같은 격자 |
| M1-R | Ridge 셀, 같은 격자 |
| D | 새 데이터 계열(tier가 `done`이 된 것) |
| G3 | 1h |
| G4 | 상위 30 |
| R | 국면 게이트 축 |

- **국면 게이트 축(R).** BTC 기준 확장 창 분위(`expanding_quantile`): 추세 국면(90일 수익률), 변동성 국면(30일 실현 변동성). `regime_gate ∈ {none, trend_up, trend_not_down, vol_low, vol_not_high}`. 국면이 맞지 않으면 포지션 0. 늘어나는 trial과 S3는 모두 회계에 들어간다.
- **결합 단계의 거짓양성.** 첫 실행 전에 귀무 하네스(블록 순열·부호 뒤집기)로 (선택 → S3 → 교차 → 결합 판정)과 M0·M1-R 전체의 거짓양성률을 잰다(200회 이상, Wilson 95% 구간). 점추정이 0.05를 넘으면 c2를 시작하지 않고 보고한다.
