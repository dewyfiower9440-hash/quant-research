# 판정 규칙 v2 보정 (v2.2 A2, ADR-042, 2026-11-20)

> 귀무 일별 pnl(평균 0)에서 판정 규칙이 "통과"를 낸 비율 = 질의 1회의 거짓양성률. 명목 α/k = 0.0025, 허용 상한 1.5 × α/k = 0.00375. 스트레스 조건은 항상 통과로 두어 SR 검정만 잰다. 측정 스크립트는 세션 scratchpad(`calib.py`, `calib2.py`)이며 코드 경로는 `validator.verdict.decide`와 `sr_test`다. **실제 전략의 성과 증거가 아니다.**

## 판정
- 사전 조건(활동일 ≥ 60, 독립 진입 ≥ 30, 평균 목표 총노출 ≥ 5%)이 희소 pnl을 판정 대상에서 뺀다(불충분 = 질의 미차감). 하니스는 불충분 복제를 미통과와 따로 센다(`HarnessResult.summary` judged·insufficient·measurable).
- **최소 holdout 길이 600일로 사전 등록**(ADR-042 보강, 실제 질의 0건인 상태에서): 250일은 밀집·AR 귀무에서 상한을 넘었고, 450일 이상은 상한 이내였다. epoch 2 역사 holdout(700일)은 이 조건을 만족한다. 전방 holdout(4개월)은 유의성 판정이 아니라 부호 조건(ADR-041)으로만 쓴다.
- PSR은 이 길이에서 블록 부트스트랩보다 엄격한 경우가 드물다(왜도 있는 240개 계열 중 1건). 독립된 두 번째 관문으로 유지한다.
- 남은 한계: AR(0.3)처럼 강한 자기상관에서 0.0036으로 상한에 가깝다(블록 10일). 전략 pnl의 자기상관이 이보다 크면 반보수적일 수 있다(미확인).
