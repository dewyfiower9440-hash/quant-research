# Phase 5 파이프라인 귀무 검증 — 종단 FWER (tools/run_null_pipeline.py, 2026-11-19)

> 신호 없는 합성 시장(실데이터 8심볼 1h 수익률의 stationary 블록 부트스트랩, 블록 24시간)에서 축소 탐색(S0 → S1 40 → 승격 3+5% → S2 → S3) 뒤 validator 판정 규칙(ADR-035: α/k = 0.0025, c = 0.5, 비용 ×2·×3·lag +1·×2 스트레스)까지 전체를 돌렸습니다.
> 반복마다 임시 research.db·catalog.db·validator.db를 만들고 지웠으므로 운영 DB에는 아무것도 남지 않았습니다. **어떤 실전 전략의 성과 증거도 아닙니다.**
> 메모리 보호로 1차 실행이 중단돼 arm별로 나눠 돌렸습니다(`phase5-null-pipeline-random.md`, `phase5-null-pipeline-tpe.md`가 원본 표).

## 판정
- 사전 등록 목표(ADR-022) FWER ≤ 0.05: **점추정은 0.03·0.05·0.04로 목표 이하이지만, 95% 구간 상한(0.085·0.112·0.077)이 0.05를 넘어 100~200회로는 "충족"을 확정할 수 없습니다.** ADR-022가 예고한 대로(100회의 반폭 ≈ ±4.3%p) 반복 확대(400~1,000회)가 필요합니다. 기준값은 바꾸지 않습니다.
- **관찰(미확인 원인):** 한 전략이 holdout 질의 1회로 통과할 귀무 확률은 α/k = 0.0025에 스트레스 조건까지 겹쳐 그보다 작아야 하는데, 관측된 4%는 그보다 한 자릿수 큽니다. 후보 원인: (1) 합성 "귀무" 시장이 24시간 블록 안의 자기상관을 그대로 보존하므로 시간 단위 전략이 블록 내부 구조를 일부 이용할 수 있다(완전 귀무가 아님) → `SyntheticSpec(shuffle=True)` 또는 블록 길이 축소로 재측정 필요, (2) 평균 블록 10일의 stationary 부트스트랩 SE가 이 합성 일별 pnl에서 과소추정, (3) 스트레스 재실행이 같은 holdout 구간을 쓰므로 통과 조건 간 상관이 높아 가드 효과가 작음. 어느 것이든 **판정 규칙을 완화하는 방향의 수정은 하지 않고**, 최종 검증 단계에서 (1)을 먼저 확인합니다.
- Random 대 TPE: 귀무에서 두 arm의 통과율 차이(0.03 vs 0.05)는 구간이 크게 겹쳐 의미를 둘 수 없습니다.

## 검정력(알파 주입, `phase5-null-pipeline-alpha.md`, arm당 30회, 584초)
| 알파 | 강도 | random 회수율 | tpe 회수율 |
|---|---|---|---|
| random(시간의 1/5에 드리프트) | 0.0015/h | 2/30 = 0.067 [0.018, 0.213] | 1/30 = 0.033 [0.006, 0.167] |
| mechanism(lag-1 평균회귀) | 0.015 | 0/30 = 0.000 [0, 0.114] | 1/30 = 0.033 [0.006, 0.167] |

- **판정:** 이 강도의 심은 알파는 귀무 통과율(0.03~0.05)과 구별되지 않습니다 → **검정력 ≈ 0.** 8심볼·선별 90일·확인 30일·holdout 약 60일의 합성 시장에서 α/k = 0.0025 기준은 매우 높은 SR을 요구하며(`min_sr` 표 참조), 심은 드리프트 0.0015/h(연 약 13%·시간 변동성 대비 작음)와 평균회귀 0.015는 그 수준에 미치지 못합니다. 강도를 키운 재측정(예: 0.005/h, 0.05)과 더 긴 합성 구간이 다음 측정 항목입니다. 기준값은 바꾸지 않습니다.
- Random 대 TPE 차이는 30회·2~0건으로 판단 불가.
